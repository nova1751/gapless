# macOS 无缝播放 0.3.8

当前源码、安装包和运行版本均为 **0.3.8**。实测宿主 **BetterNCM-mac 0.1.7**、网易云音乐 **3.1.12（3444）**；独立菜单扩展版本 **1.1.1**。宿主版本、菜单版本与无缝插件版本分别显示／记录，不能混用。[版本与哈希](../docs/versions.json)，[本轮菜单／市场验证](../docs/verification/mac-menu-click-1.1.1.json)。

## 本次更新

菜单 1.1.1 修复市场左侧「无缝播放」无响应，点击后打开右上角现有开关与状态；不另建设置页，不改变播放意图。市场顶部和菜单统一明确提示：市场主要面向 Windows，很多插件在 macOS 不能直接使用。

- 右上角原插件按钮默认打开「无缝播放」开关、状态和「管理已安装插件」。保留原生按钮、宿主开关及认证 API，新增样式限定在菜单弹层、重复入口隐藏及市场说明内。
- 管理页列出本机已安装插件及宿主内置项，展示版本和宿主兼容说明；本机已开启宿主原 PluginMarket 0.8.0，可从右上角「插件市场」浏览。下载和安装由用户选择；依赖 Windows DLL／桥接口的插件不代表兼容 Mac。
- 版本标签来自宿主安装清单，悬停显示安装与运行版本；不一致时提示重启更新。无缝运行版本由打包时的 manifest 自动注入。
- 修复页面恢复后首次关闭、同曲尚无原生 Load 时的恢复失败：使用已验证的原生 SDK 重建同曲实例，保留授权音源，再 Seek 并恢复最新暂停或播放意图，避免完整选曲的迟到状态更新。开关保存串行执行，管理视图切换期间不能重复提交。

未修改音源选择、解码、音量曲线、采样率策略、音乐排程、歌词或频谱算法。未知客户端版本保持原生。

## 安装与回退

```sh
python3 mac/package.py
python3 mac/install-menu.py --market
```

1. 生成 `dist/gapless-player-mac-0.3.8.plugin`，交付副本见 [0.3.8 包](../releases/gapless-player-mac-0.3.8.plugin)。复制到 `~/Library/Application Support/BetterNCM-mac/plugins/`；同 slug 只留一个活动版本，旧包移到目录之外。
2. 菜单安装脚本只写 `/Applications/BetterNCM.app/Contents/Resources/app/src/prelude/gapless-plugin-menu.js`，不改宿主原文件，不修改 CSP。`--market` 仅将指定 profile 的 `mac.pluginManager` 保存为 `true`，复用已内置的 PluginMarket，其他配置不变；不加该参数仅更新菜单，保留市场原有设置。宿主 API／自动发现接口不匹配时退出，保留原菜单。非默认安装位置可加 `--app /path/to/BetterNCM.app`；自定义 profile 加 `--profile /path/to/profile`。
3. 由宿主重载插件并刷新页面，或正常退出后重新打开。核对菜单安装版本、`gaplessMac.version` 和 [当前状态](../docs/CURRENT_STATUS.md)。初次真实输入之前 Web Audio 可以等待授权，不主动发声。

移除菜单扩展：`python3 mac/install-menu.py --remove`，下次重载恢复宿主原菜单；已保存的市场启用设置保留，无缝播放包与其独立。播放器回退可关闭无缝开关，或正常退出后换回插件目录之外备份的 0.3.7 包。本机已保留旧包。宿主升级可能移除独立 prelude；升级后需重新检查接口并安装。

宿主原管理页标题的 **1.3.4** 是模拟的 BetterNCM 兼容接口版本；新增说明显示实际 Mac 宿主 **0.1.7**。无缝插件、菜单和宿主分别版本化，市场中的第三方插件另有各自版本。

## 播放与缓存

同源、同档位内存 → 原生有效磁盘区间／原生解析器返回的明文本地 FLAC → 原生串行 Load → Seek → Stop 准备缺口、提交缓存。辅助实例不 Play，通知不覆盖主曲目、歌词、进度或系统状态。插件只读有效数据并解码，不写 UC／IDX，不建立第二套永久音乐缓存。

编码区块共享 64 MiB，索引路径每首 PCM 32 MiB，其他路径受 512 MiB 管理预算约束。当前曲、用户 Seek 优先；当前 PCM 余量足够后才后台补齐，任务有期限并可取消，不保证退出前整首落盘。同采样率预约连续输出，异率重建上下文可能有短间隔。

无缝开关优先，Web 输出期间不执行冲突的原生音效，保存值供关闭后原生使用。关闭恢复原生并释放工作缓存，重新开启可准备当前曲。系统控制中心进度回跳仍有原生对照问题，不能宣称完全解决。
