# macOS 无缝播放 0.3.12

当前源码、安装包、宿主运行文件和实际页面均为 **0.3.12**。宿主 **BetterNCM-mac 0.1.7**、网易云 **3.1.12（3444）**，管理入口 **1.2.1**。[版本与哈希](../docs/versions.json)，[本轮进度修正](../docs/PROGRESS_RECOVERY_0.3.12.md)。

## 本次更新

0.3.12 修正缓存读取失败回退原生后，网易云仍停在「首次加载中」、进度条显示 00:00 的问题。有待完成的原始 SDK Load 时复用其授权资料和加载回调，不嵌套调用 SDK Play 覆盖订阅；恢复原生后完成原始 Load，让客户端自行清理加载状态。缓存错误不再强制重新选曲。实际故障注入后原生与界面进度继续推进；宿主缓存服务恢复、页面重载、暂停位置恢复已完成。

0.3.11 修正正常从头播放也可能在曲尾附近出现的 FLAC 分块解析短结果：用有界下一帧前瞻和流式解码确定边界，采样数与格式仍须完全匹配，检查内置解码器真实错误数组，并保留区间失败原因。123 个原生缓存索引区间通过，原问题段 PCM 与连续解码逐采样一致。该修正已包含在当前完整 0.3.12 页面，数值证据保留原版本。

0.3.10 修正无关队列更新也撤销预约的问题：实际下一首、源规格、输出时钟及边界仍匹配时保留预约；接认阶段从原曲重新计算下一首，确认同一队列项后保留接认。真正的选曲、账号／档位／源变化、输出或缓存故障仍有原生回退。`gaplessMac.status().lastFallback` 保留本次页面最近一次切回原生的原因、位置和源采样率。[修正范围与 Windows 建议](../docs/QUEUE_BOUNDARY_0.3.10.md)。

右上角插件按钮打开宿主样式快捷菜单：上方「无缝播放」开关，下方「管理插件」。点击管理插件进入宿主原 BetterNCM 管理页，左侧列出全部已安装插件，右侧展示所选插件详情、启停及其原有配置。无缝插件通过 BetterNCM `onConfig(tools)` 和 `tools.makeCheckbox` 提供「无缝播放」；勾选开启，取消勾选关闭并交回原生。快捷开关与配置复选框同步，保留原页面、侧栏和卸载行为。

- 无缝启停沿用播放器已有串行保存／原生恢复流程，实时状态和保存值同步。插件没有加载时，启用后通过宿主刷新加载；从管理页操作时自动回到管理页，从快捷菜单操作时保留网易云页面。
- 插件市场是 PluginMarket 0.8.0 插件；开启后显示市场目录，关闭后管理入口与无缝控制保留。其他插件启停需要页面刷新，管理页会自动重新打开。
- 管理页显示安装版本和可用的运行版本；快捷菜单显示安装版本。0.3.9 注册原生 `onConfig` 回调，让已加载的无缝插件侧栏可点击，右侧展示插件自己的无缝复选框。
- 显示「市场主要面向 Windows，很多插件在 macOS 不能直接使用」，下载和安装由用户选择。没有自动下载／安装其他插件。

本轮修改原生回退的加载生命周期；未修改音源选择、音量曲线、采样率策略、歌词或频谱算法。0.3.8 的同曲原生恢复修复继续保留。

## 安装与回退

```sh
python3 mac/package.py
python3 mac/install-menu.py
```

1. 生成 `dist/gapless-player-mac-0.3.12.plugin`，交付副本见 [0.3.12 包](../releases/gapless-player-mac-0.3.12.plugin)。复制到 `~/Library/Application Support/BetterNCM-mac/plugins/`；同 slug 只留一个活动版本，旧包移到目录之外。本机已保留 0.3.11 回退包。
2. 菜单安装脚本只写 `/Applications/BetterNCM.app/Contents/Resources/app/src/prelude/gapless-plugin-menu.js`，不改宿主原文件，不修改 CSP。`--market` 仅将指定 profile 的 `mac.pluginManager` 保存为 `true`，复用已内置的 PluginMarket，其他配置不变；不加该参数仅更新菜单，保留市场原有设置。宿主 API／自动发现接口不匹配时退出，保留原菜单。非默认安装位置可加 `--app /path/to/BetterNCM.app`；自定义 profile 加 `--profile /path/to/profile`。
3. 由宿主重载插件并刷新页面，或正常退出后重新打开。核对菜单安装版本、`gaplessMac.version` 和 [当前状态](../docs/CURRENT_STATUS.md)。初次真实输入之前 Web Audio 可以等待授权，不主动发声。

移除菜单扩展：`python3 mac/install-menu.py --remove`，下次重载恢复宿主原菜单；已保存的市场启用设置保留，无缝播放包与其独立。播放器回退可关闭无缝开关，或正常退出后换回插件目录之外备份的 0.3.11 包。本机已保留旧包。宿主升级可能移除独立 prelude；升级后需重新检查接口并安装。

宿主原管理页标题的 **1.3.4** 是模拟的 BetterNCM 兼容接口版本；新增说明显示实际 Mac 宿主 **0.1.7**。无缝插件、菜单和宿主分别版本化，市场中的第三方插件另有各自版本。

## 播放与缓存

同源、同档位内存 → 原生有效磁盘区间／原生解析器返回的明文本地 FLAC → 原生串行 Load → Seek → Stop 准备缺口、提交缓存。辅助实例不 Play，通知不覆盖主曲目、歌词、进度或系统状态。插件只读有效数据并解码，不写 UC／IDX，不建立第二套永久音乐缓存。

编码区块共享 64 MiB，索引路径每首 PCM 32 MiB，其他路径受 512 MiB 管理预算约束。当前曲、用户 Seek 优先；当前 PCM 余量足够后才后台补齐，任务有期限并可取消，不保证退出前整首落盘。同采样率预约连续输出，异率重建上下文可能有短间隔。

无缝开关优先，Web 输出期间不执行冲突的原生音效，保存值供关闭后原生使用。关闭恢复原生并释放工作缓存，重新开启可准备当前曲。系统控制中心进度回跳仍有原生对照问题，不能宣称完全解决。
