# Windows 0.4.6 / Mac 0.3.3 主要能力对齐

日期：2026-11-16。基于 main `9dcef8c`，按用户要求补上 Mac 本地 FLAC 和切歌后补缓存。Mac 0.3.3 已打包安装并完成相关实机检查；Windows 保持既有播放器和缓存策略，仅修正共享解码入口的本地身份落地。Windows 0.4.6 新候选本轮未安装或实机复测，不据此宣布全平台完整验收。

## 能力矩阵

| 能力 | Windows | Mac | 对齐与限制 |
|---|---|---|---|
| 在线有索引 FLAC | 原生授权、取数、持久缓存 | 同一职责，Mac UC/IDX 适配 | 插件只读有效区间并解码；文件长度/百分比不能证明完整 |
| 持续输出 | Web Audio 同时钟预约 | 同左 | 同采样率连续；不同采样率重建，允许间隔 |
| 编码与 PCM 工作缓存 | 编码共享 64 MiB、索引 PCM 每首 32 MiB | 同左 | 退出释放，不新增永久缓存 |
| 前台缺口与 Seek | 原生串行任务，前台优先 | 同左 | 有限等待、取消、失败回原生 |
| 后台补齐当前与旧曲 | 当前 PCM 足够时补齐，最近两首/十分钟元数据 | 0.3.3 已补 | 八秒截止、六次无进展停重试；不保证退出前整首完整 |
| 本地有索引 FLAC | 已有原生本地列表实测 | 新增原生所选明文路径适配，真实文件和原队列动作实测 | Mac 未新增或验收原生扫描/导入 UI；不保证加密下载/CUE |
| 本地文件版本 | 原生文件属性和接认复核 | 大小/修改时间，读取前后、起播/恢复及接认复核 | 元数据不是全文件内容证明；不复用已报告变更的旧 PCM |
| 暂停/恢复、连续 Seek | 既有意图与实例保护，新候选待复测 | 本轮本地、在线及回退已检查 | SDK Load 后原客户端默认恢复 Seek 仍有竞态 |
| 歌词、频谱、节拍 | 原 UI、显示 PCM 及实际输出时钟 | 同左，既有 0.2.3 修复沿用 | 不改变原动画算法、布局、音效或音质 |
| 开关/插件注入 | 右上角原样式入口，关闭交还原生 | 原宿主插件菜单，关闭交还原生 | 符合各自 UI；不要求两端像素相同 |
| 系统媒体 | SMTC 状态/控制；历史宿主无时间线 | 系统状态与 Seek；已知面板回跳 | 能力差异保留，未宣称完全一致 |

## 实机结果

- 本地两份真实 44.1 kHz FLAC 经原生解析器返回可播放路径，再由原队列动作加载；未伪写原生歌曲库。首次资源提交 113 ms，暂停后 117 → 34 秒 Seek 保持暂停，继续可用。曲尾 Seek 后自然跨至 Open Hearts，预约间隔 0 帧、宿主接认 121 ms；接认等待不等于断音。应用音频采集为 48 kHz，跨曲前后 ±1 秒内无双声道全零或低于 -80 dB 的采样段，PTS 无缺口。这是一对曲目的应用采集，不是 DAC/蓝牙或所有音源保证。
- 本地回录在迟到 Load 保护补修前包执行。文件修改时间变化时实机复现回退后 SDK 被第二次 Load 通知自动唤醒；补修把原生重建的 Load 通知持续隔离到下一次真正选曲。最终安装包收到两次原生 Load 后仍保持原生暂停和 117 秒，Web 内存归零；随后手动继续正常。首次非原生格式的人工字母 ID 在原生回退中超时；后续改用原生支持的数字前缀 ID 验证，未以该超时宣称原生文件不支持。
- 新歌 Intoxicated 最初没有原生缓存。切至 Open Hearts 时，IDX 有效区间为 `[0, 43489915)`，整首大小 51,532,448 字节；切走后补至 48,880,089 字节，再提交完整 IDX `[0, 51532448)`。整首解密后 MD5 与授权源一致。后台期间没有新增原生 Play，当前曲仍由 Web 输出、元数据保持当前曲。原生写盘仍由 Load → Seek → Stop 完成。
- 正常退出并重新启动后，插件播放新歌直接命中磁盘，原生辅助取数批次为零。关闭无缝后，原生播放器可播放同一缓存源，编码文件内容哈希/大小未变；修改时间变了，未审计全进程网络，不能宣称完全没有请求。
- 最终包在原收藏队列完成在线 Baptized In Fear → Open Hearts 跨曲和接认，预约 0 帧，无回退/欠载记录。跨曲后 Seek 至 117 秒、暂停正常；歌词与原播放页显示保留，显示 PCM 按输出时钟更新，未报告显示故障或跳帧。系统会话状态正常；控制中心回跳和图标外观不靠协议记录冒充已修复。

起播 `loadMs` 是插件资源提交耗时，未包含冷启动、授权网络、真实用户输入及设备开始出声的全部等待。一次后台补齐成功不代表弱网、任意格式和退出时机都能补全。新后台生命周期沿用既有清理屏障，本轮没有重新删除整个用户缓存；清缓存实机证据仍见 [Mac 0.3.1](MAC_NATIVE_CACHE_0.3.1.md)。

## 交付

新增 `mac/local-source.js` 只读适配和 `shared/native-cache-fill.js` 有界调度；Mac 保留主播放器控制。共享流式入口将解码后本地身份同时用于 PCM 和编码区块键，避免下一首异步解析路径得到空身份后把不同文件版本混用。Windows 不移植一套重复实现。

最终收尾补上本地文件属性读取的三秒截止与取消，以及本地接认被新操作替代时的失败回复，避免等待悬挂。安装后实际文件属性读取成功；超时和旧接认分支按增量代码审查确认，本轮未人工制造系统挂起或重做跨曲回录。

修改 JS 语法、Python 解析及 Mac ZIP/运行文件比对通过；未新增测试、全量静态检查或应用构建。旧 0.3.2 包保留在插件目录之外，原曲、原队列、Hi-Res 选择和暂停位置已恢复。音频、缓存、账号、签名 URL 与临时文件未入库。

系统媒体回跳、SDK 加载默认 Seek、不同采样率、无索引/未知格式、弱网、设备输出和元数据未变的文件内容替换仍有明确限制。[脱敏证据](verification/platform-alignment-0.4.6-0.3.3.json)，[前一轮控制保护](PLATFORM_ALIGNMENT_0.4.6_0.3.2.md)。
