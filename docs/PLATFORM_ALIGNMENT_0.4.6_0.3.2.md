# Windows 0.4.6 / Mac 0.3.2 功能对齐检查

日期：2026-11-16，基于 main `ba38c91`。本轮对齐受支持的在线播放、控制保护和默认打包入口。Mac 0.3.2 已安装；Windows 0.4.6 为源码候选，本机没有 Windows 宿主或精确客户端归档，未打包、安装或实机复测。不能据此宣布完整跨平台验收。

## 本轮修正

- Windows 默认包改为原生缓存数据源。`--native-source-trial` 保留为兼容参数；`--web-source` 明确选择旧 Web 网络取数，产物带独立后缀。诊断和公开状态同时标注版本与数据源模式，避免不同实现只靠相同版本号区分。
- Windows Seek 回复携带请求自己的代次。旧 Seek 被新控制取代后返回失败及当前实际位置，不把旧目标发布成成功进度；取消路径保留回调完成。
- Windows 输出初始化及原生静音握手完成后，再等待最新偏移的可播放 PCM；有未完成 Seek 时，Load 自动开始和手动继续均不从旧位置启动声音。
- Windows 随机预约保留原客户端选择器，只在客户端能力及完整、唯一随机顺序均可证明时启用；未知仍不预约。
- Mac 增加曲目变速字段和嵌套音效开启字段保护。加载期间已暂停再 Seek，暂停保护继续绑定最新控制代次，避免原 SDK 自动 Play 改掉暂停意图；自动 Play 保护只在加载完成时生效，加载期间的手动继续仍能更新意图。

## SDK 能力必须按平台判断

实际 Mac 3.1.12 的 `AudioPlayer.switchEffect`、`setOutputDevice` 返回 true 且没有原生调用，`subscribeOutputDevices` 为空实现；当前 `playFade=true` 不代表该接口真的启用了原生淡化。直接照搬 Windows 的 fade/device 判断会让 Mac 默认无缝播放被禁用。本轮保持 Mac 已验证的保护集合，不修改原设置；这不证明底层设备、全部 DSP 或音质输出与 Web 完全相同。Windows 已有实际开启 fade 后回原生的证据，继续保留其保护。

## 本轮验收与明确限制

Mac 包与解压 runtime 七个文件逐字节匹配，JS 语法和 ZIP 完整性通过。真实客户端恢复原曲、暂停/继续、连续 Seek 和关闭回退已核对。连续 120 → 180 秒时，旧请求返回 -1，新请求返回 0/180，保持暂停。关闭约 24.3 ms，原位置 1.911451 秒保持暂停、解除原生音量门控、工作内存归零。这项关闭检查在最后补修前的 0.3.2 包执行，补修只涉及加载 Seek 的暂停保护。

最终包在页面快照恢复的加载期间暂停、Seek、继续、再暂停，逐项保留最新意图；真实输入后加载完成仍保持 1.911451 秒与暂停。前一包在原生选曲 Load 流程中暂停并直接 SDK Seek 后，缓冲完成保持暂停，手动继续仍能播放。资源重新进入 Web 的 loadMs=187，不含之前等待真实输入的时间，不能当作完整冷启动出声耗时。此前原生选曲流程中，原客户端随后自动 Seek 到保存的整数位置 1 秒，覆盖了直接 SDK 请求的 1.911451 秒；没有宣布此加载位置竞态已解决。普通播放完成后的 SDK Seek 可恢复准确位置。最后恢复 YOU feat. kazami、1.911451 秒、暂停、无缝启用，原生缓存读取无故障。

Baptized In Fear → Open Hearts 的实际跨曲声音、缓存提交/重启复用、清理及歌词频谱沿用 [Mac 0.3.1 实机证据](MAC_NATIVE_CACHE_0.3.1.md)，本轮没有新音频回录。Windows 原生数据源安装仍以 `aae1d55` 的 [记录](verification/windows-candidate-install.json) 为准；0.4.6 仅修改文件语法、Python 解析及参数冲突检查通过，不能当作 Windows 控制/随机/启动验收。

保留已知系统进度回跳、Windows SMTC 无时间线、原客户端 Load 完成恢复位置、手动换曲等待、格式/弱网/设备与后台补齐限制。只读源码和有限场景不足以宣称零副作用或全平台完全对齐。没有新增测试、全量静态检查或应用构建。安装旧包已保存在插件目录之外；音频、账号、签名地址和原生缓存未入库。
