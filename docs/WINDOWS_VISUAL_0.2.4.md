# Windows 0.2.4 动画修正

基于实际已安装 Windows 0.2.3；核对 main 08f1ca6。旧包保存在仓库外备份目录。

修正 Windows AudioData 为独立 ArrayBuffer；按 pts 记录有效字节长度，在原生 WASM 分析入口限制到本次数据长度，防止消费者沿用旧大缓冲区的长度读取残留。仅在页面可见、原生订阅启用、Web 正在播放时生成显示数据。取消强制开启原动画计时器；保留原渲染循环、样式和暂停控制。SDK 只发现一次，避免每 40 ms 注册临时 webpack 模块。仅接入实查的渲染和播放位置函数。

实机：Baptized In Fear → Open Hearts，lossless FLAC，源/解码/输出上下文均 44100 Hz，同一 context generation 2；预约间隔 0 帧。下一首到 35 秒仍由 Web 播放，没有十秒交还。暂停后显示数据帧计数不变；歌词、唱片旋转和频谱可见推进；原生关闭按钮布局正常。原渲染调用约 33 ms 一次，与 PCM 同用输出位置。完整记录见 verification/windows-visual-0.2.4.json。

限制：0 帧是预约参数，未做本版本声卡回录；Windows 首次播放仍原生接管，不是 main Mac 的完整 Load 接管移植。随机、不同采样率、不兼容设置仍有限制。显示数据沿用 48 kHz s16le；已确认 Windows 原生包为 ArrayBuffer 且常见 12800 字节，尚未证明显示重采样与原生所有效果的幅度完全一致。显示数据不接入音频输出图，不改变音乐音源、增益或采样率。Web float32 解码和系统转换不能保证与原生比特相同。原生系统媒体控制复活旧后端的风险仍需独立处理。

最终包关闭常驻诊断；未引入 CSS、主题、音效或音质选择。临时录音已清除。
