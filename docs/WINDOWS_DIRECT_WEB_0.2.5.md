# Windows 0.2.5：从 Load 直接使用 Web Audio

核对上游 main 08f1ca6，移植普通受支持歌曲的直接 Load / 已暂停实例继续播放路径。网易云仍决定授权音源、音质、队列和控制界面；插件在原生 Load 发往后端前准备同源 PCM、打开源采样率上下文、静音原生后端，然后响应原有 Load 事件。无需先让原生发声再暂停接管。未关闭的旧原生实例不能与 Web 叠音。正常跨曲不触发十秒交还。

播放、暂停、Seek、音量通过原有控件进入；加载期间保留控制意图。取消/新选曲之后异步任务不能启动旧歌曲。加载中暂停后的自动 play 回调被抑制，使用已核实的客户端 playing/pause 操作完成按钮状态同步；初次 Load 后的自动 Seek 不应取消暂停意图。没有修改 CSS、标题栏、歌词布局、音乐 DSP 或音质选择。

只要来源/规格/设置不兼容或准备失败，原样调用原授权 Load 回退原生，不换低档音源。不同采样率不在同一输出上下文预约，而在下一次 Load 重建匹配源采样率的输出。首次下载/完整解码仍有等待，不能承诺点击即响或所有跨采样率边界无缝。启用插件前已经发声的原生歌曲不会在中途强制切换；下一次点选或已暂停后继续才直接使用 Web。

实机 Windows 3.1.43.205627：
- 收藏列表点选 Baptized In Fear：web-loaded，原生 onLoad/onPlayState 监听为零；原生输出静音。
- 暂停、Seek 到曲尾后继续，Baptized In Fear → Open Hearts 使用同一 44100 Hz 上下文，预约 0 帧，仍无原生播放事件。
- 模拟一次资源准备失败，准确回退原生 Load/Play，音量恢复到原有约 0.72；已暂停的原生继续播放也直接进入 Web，无新增原生播放事件。
- 最终控制检查：延迟加载途中暂停，Web 活动节点为 0，网易云 playingState=1（Pause）；快速换歌后只有最后选中 Open Hearts 获得播放所有权。
- 包装 JS 语法检查通过，未运行全量构建或新增测试用例。

见 verification/windows-direct-web-0.2.5.json 和 windows-direct-controls-0.2.5.json。预约 0 帧不是声卡回录证明。本轮未回录；无法声称与原生比特相同，也未验收所有系统媒体键、设备切换及格式。0.2.4 动画适配继续保留。
