# Windows 0.2.6：缓存复用与右上角开关

参考 Mac native-cache.js 的只读缓存策略，适配实查 Windows 3.1.43 的 Storage.getTrackFromCacheFast、cacheDir/Cache 目录及 id-bitrate-md5.uc 文件名。要求原生记录 cached=100，曲目、档位、MD5、长度、普通非试听音源元数据一致。通过宿主本地挂载流式读取，内存 XOR A3 还原后核对完整 MD5，继续经过共享采样率/声道/预算校验。缺失或完整性失败仍使用同一授权网络源。不改动网易云缓存和索引，不复制账号或音源 URL 到诊断文件。

已测 Baptized In Fear / Open Hearts 两份无损 FLAC 命中缓存、MD5 通过、插件音频网络请求为零；源/解码/上下文均 44100 Hz。模拟校验失败可回到相同音质网络源；验证期间未修改缓存文件。

右上角独立无缝开关复用客户端按钮样式，显示开/关，主页面与歌词页共用一个控制。仅定位自身，不修改原有 grid、标题栏、窗口按钮宽度。实机点击关闭后恢复原生、解除原生静音、清理音频缓存；再点开启成功。原生窗口按钮在开关显示/隐藏前后矩形完全一致。窗口较窄而无可用空间时隐藏快捷入口，设置页开关仍可使用。开关开启不会强行切换已经发声的原生曲目，下一次选曲或暂停后继续时生效。

范围：这是复用现有网易云磁盘缓存，不是新增网络歌曲的磁盘缓存写入器。Web 请求的新歌曲不会由本插件写回网易云私有缓存；这与本轮参考的 Mac 只读方案一致。网易云没有匹配缓存时仍需网络请求。下载的加密 NCM 文件仍走原生，普通本地 FLAC/MP3 路径保持原有支持。

证据：verification/windows-cache-toggle-0.2.6.json。最终包关闭诊断日志，旧版已备份于仓库外。
