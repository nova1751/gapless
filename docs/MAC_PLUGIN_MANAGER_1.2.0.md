# Mac BetterNCM 管理页 1.2.0

本文保留 1.2.0 的实现与验收记录。当前右上角快捷开关及「管理插件」入口见 [1.2.1](MAC_PLUGIN_QUICK_MENU_1.2.1.md)。

Mac 无缝插件 0.3.9、管理入口 1.2.0；基于最新 main 868a64e，保留 Windows 0.4.14。版本和哈希见 [版本记录](versions.json)。

## 使用

右上角插件按钮直接打开 BetterNCM 原管理页。左侧列出全部已安装插件，包括已关闭的项；点击后右侧显示名称、安装／运行版本、说明、启停及插件自己的详细配置。没有外部无缝快捷开关或第二个设置页面。

选中「无缝播放」，右侧勾选「无缝播放」开启，取消勾选关闭并恢复网易云原生播放。该控件使用 BetterNCM `onConfig(tools)` ／`tools.makeCheckbox`，沿用现有无缝启停事务；保存和恢复期间禁用重复操作，最终勾选状态与实际运行和宿主保存值一致。

选中「插件市场」，右侧可启停 PluginMarket。开启后同页显示其原有市场目录，关闭后目录不加载，但 BetterNCM 管理入口、已安装插件列表和无缝控制仍可使用。管理入口属于宿主集成，市场属于可关闭的插件。

## 与 Windows 的对应

Windows 0.4.14 同样通过 BetterNCM 原侧栏选择插件、原配置回调提供无缝复选框；最新提交还支持网易云左上角返回关闭管理页。Mac 复用这个配置与导航方式，保留平台独立的认证 API 和启停恢复流程。

Windows 仍有已有的右上角快捷菜单；Mac 按本次用户要求直接进入管理页。没有为界面对齐改动 Windows 音频或菜单代码，也没有把 Mac 验证记作 Windows 实测。

## 实现边界

- 已加载插件侧栏、配置回调和卸载处理由宿主保留。只补齐宿主未列出的关闭／内置项及其详情，未加载插件的配置代码不会为浏览而执行。
- 右侧详情区保留原有配置内容；每次切换由宿主回调显示，扩展只增加版本、说明和启停。没有仿造第三方配置或额外音频选项。
- 无缝的实时启停不刷新页面；其他非内置插件启停需宿主重载，刷新后恢复管理页及所选插件。关闭后重新加载页面，无缝代码不注入；可从左侧重新启用。
- 网易云返回按钮在管理页开启时关闭该页；原页面返回继续由网易云处理。右上角入口和 Esc 也能关闭。
- 仅使用已安装宿主的认证插件 API；不修改 CSP、权限或宿主原 bundle。管理入口是独立 prelude，卸载扩展可恢复原宿主菜单。
- 市场主要面向 Windows，很多插件不能直接在 Mac 使用，特别是 DLL／原生接口依赖；提示始终可见，下载／安装由用户决定。

## 验证

本轮使用 Mac 原生界面和运行诊断核对列表、详情、无缝复选框、保存和原生恢复、关闭插件后的重新启用、市场启停及管理页返回。具体结果与哈希见 [机器记录](verification/mac-plugin-manager-1.2.0.json)。无缝 0.3.8 旧包保留回退。

0.3.9 仅增加配置回调和版本号，没有改动解码、增益、采样率、排程、歌词或频谱算法。未新增音频 A/B、第三方插件安装、全市场兼容验收、测试用例或全量静态检查。历史播放证据保持原版本。
