# 本地歌曲缓存身份修正（2026-11-16）

实际源码复现：`AudioResources.obtain` 对同一路径、宿主 `fileSize` 从 100 改为 200 的请求，仍返回旧 PCM，`openLocal` 调用次数为零。原身份只含路径；Windows `source.same` 也只比较路径。

现在本地身份包含规范化路径、有效文件大小及可用内容指纹。内存命中、在途任务合并、失败重试身份及 Windows 接认均使用这些信息；大小或内容指纹变化不再复用旧条目。在线身份算法不变。缺少大小使用 null，不伪造文件版本。

临时 Node 检查执行实际资源类和 Windows 适配器，验证相同元数据复用、大小变化、同大小哈希变化、路径规范化、不同身份在途请求分离、非 exactSize 本地路径及在线身份不变；修改文件语法和 Windows trial ZIP 打包通过。没有新增常驻测试。此修正已安装为 `6c98ad3`，安装包与 runtime 一致；重启后在线播放加载 1113 ms、44.1 kHz，未观察到回退，原托盘设置已恢复。真实本地文件替换仍未验收。
