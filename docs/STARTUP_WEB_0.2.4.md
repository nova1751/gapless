# 0.2.4 首曲直接进入 Web

启用无缝模式时，在原生声音开始前决定后端，受支持曲目的第一段声音直接由Web播放。页面重载后的有效快照也直接恢复Web，取消原先先恢复原生、再追赶接管的路径。首次读取/解码仍需等待；首次真实输入授权也可能需要等待，这属于出声前准备，不是两条已出声播放线之间的切换。

## 入口及取消

- `mac/startup.js`在原生桥出现时安装入口。适配器未就绪则暂存第一个Load及相关控制，最多2.5秒、32条命令；就绪后按原参数和顺序交给播放器。未知版本、试听及非曲目请求放行原生。
- 初始化超时释放同一原生请求，记录本次实例为原生所有权，避免随后心跳追赶切Web。普通Web资源准备仍使用已有独立限额。
- Web上下文等待真实输入时，保留尚未完成的Load；真实键盘/指针输入后继续。换曲、Stop/Unload、关闭和恢复结束旧请求，不让旧任务改变新实例。
- 恢复快照与新鲜Load资料分开。快照没有SDK请求序号，不广播假的Load完成；新鲜Load保留当前实际授权资料，控制代次变化保留最新意图。原生SDK的自动Play保护仅覆盖对应Load回调，避免误拦之后的手动继续。
- 原生恢复复核onLoad订阅。Mac SDK在首次实际Load时才注册此事件；缺失时先走网易云原有选曲流程建立订阅，再确认加载、Seek和暂停/播放。恢复开始即清除Web加载状态，等待输入时关闭也不残留加载指示或丢失位置。

音乐解码、采样率匹配、输出时钟、曲目预约、音量和只读显示PCM算法未修改。网易云仍决定授权、音质和队列，窗口及频谱样式保留。

## 本轮核对

| 场景 | 实际观察 |
|---|---|
| 页面重载恢复暂停的Open Hearts | Web等待首次输入，保存位置177.850190秒；没有向原生发送Load/Play/Pause |
| 第一次真实空格 | 一次即可开始Web播放，窗口显示暂停按钮；原生Load/Play/Pause仍为零 |
| 普通暂停及Seek | Web仍为所有者；暂停与177.850190秒位置恢复通过 |
| Open Hearts→Moth To A Flame | 同44100Hz上下文预约和实际跨曲，预约间隔0帧；原生模型约125毫秒后接认，未启动原生音乐 |
| 原控制适配器暂时不可用1秒 | 真实SDK选曲Load被暂存，后交Web；加载期间Pause保留，SDK自动Play未重新播放 |
| 原控制适配器持续不可用 | 受控延迟3.3秒，2.5秒限额后Native Load/Play各一次；SDK播放Promise完成，保持原生所有权 |
| 等待首次输入时关闭 | 首次检查发现未注册onLoad导致恢复超时；修复后通过原选曲恢复，仍暂停于177.850190秒；Web缓存及在途预留归零 |
| 来源准备失败回退 | 一次受控来源输入触发native-only-format；恢复选曲、Load、Seek、暂停确认成功，位置保留 |
| 安装和最终状态 | 发布ZIP、安装ZIP及全部运行文件一致；运行0.2.4、开关开启、Open Hearts暂停于177.850190秒，窗口原有样式 |

初始化延迟场景是实际客户端SDK/原生桥上的短时受控检查，非完整进程冷启动验收。直接恢复与真实快捷键在最终完整安装包复验；跨曲和延迟场景随后只增加了回退订阅及加载状态修复，音乐核心与启动桥未改变。没有新增测试用例，没有执行全量静态检查或应用构建；使用增量JS语法、代码、真实协议、窗口观察和ZIP一致性核对。

原生命令计数覆盖JavaScript桥发出的Load/Play/Pause/Seek/Stop/Unload，不覆盖原生进程独立的系统媒体处理器，不能替代声卡输出测量。`native-load`日志名称表示入口观察到的SDK请求，并不表示该请求已放行原生；应结合计数判断。

## 仍有边界

完整进程冷启动、自动播放恢复、断网/设备切换及所有快速控制竞态尚未穷举。本轮未做硬件/声学输出回录，不能宣称所有场景零卡顿。插件注入前已响的原生音乐、故障恢复和关闭仍可能需要后端交接；不同采样率按新规格重建输出仍可能有间隔。系统控制中心进度回跳仍未解决，本轮没有扩大其处理范围。

最后增加了原生恢复已播放时直接确认SDK自动Play的保护，避免重复原生Play；该分支完成语法和代码检查。最终完整重载后，窗口工具未能返回画面（cgWindowNotFound），但其空格输入实际已送达，协议再次确认直接Web起播、原生命令计数为零；随后经SDK恢复原曲暂停位置。此前完整窗口观察确认原有按钮和样式，最终这一次未追加画面确认。完整包和安全字段记录见[本轮验证](verification/mac-startup-web-0.2.4.json)。[Windows方案v15](WINDOWS_CONTINUOUS_WEB_AUDIO.md)补充相同入口、手势和回退契约；Windows尚未实现。
