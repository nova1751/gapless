# Mac 0.3.1 原生取数与播放稳定性

基于 main `aae1d55`，已在网易云 macOS 3.1.12（3444）、BetterNCM-mac 0.1.7 安装并核对。Windows 源码与安装不变。证据见 [本轮记录](verification/mac-native-cache-0.3.1.json)；历史版本和 Windows 实测不能替代这份 Mac 记录。

## 数据与缓存所有权

受支持的在线、有索引 FLAC：网易云原有解析器决定权限、实际音质和音源；插件优先复用同源内存区块及原生磁盘有效区间。缺区块时串行调用独立辅助实例的 Load → Seek → Stop，由网易云下载、写 UC/IDX；插件只读取索引证明已提交的范围，在内存 XOR A3、增量解码，再由 Web Audio 连续输出。辅助实例没有 Play，也不把 Web 下载写成原生缓存。辅助通知被隔离，不能覆盖曲名、歌词、进度和系统状态。

实机刷新授权后，无 Play 的取数产生可读区间；三个 32 KiB 区间与同一授权源逐字节一致。UC 长度 61,606,634，但当时索引只证明 `0..61,382,502` 有效。原生 cached=100 也可能对应部分区间；文件长度、百分比、onLoad/缓冲通知均不单独视为完整。读取前核对 id、档位、MD5、授权元数据、长度和稳定索引；读取后复核文件版本与清理代次。完整编码区块齐备后核对整首 MD5，不能说首声前已完成整首校验。

单次原生任务保留 500 ms 获取窗口，每个区间读请求最长 8 秒；当前 Seek、当前播放、下一首依次优先。高优先级抢占后，旧 Stop 完成才开始新 Load。换曲、Stop/Unload、关闭、账号或档位变化和清缓存取消旧任务；有效性、实例和最新意图在每次等待后重新检查。清缓存先停止辅助任务，再由原生处理原请求；期间禁止读新范围。Stop RPC 后的保守等待不能证明所有客户端的原子 flush。

编码区块共享上限 64 MiB；有索引路径每首 PCM 上限 32 MiB；全部仍受资源总预算约束。这些是进程内工作缓冲，关闭释放，不是第二套永久音乐库，也不是总进程 RSS 上限。不做后台整首补齐，不保证跳到曲尾或提前退出能缓存整首，不为补齐阻塞播放。缺可靠索引时只允许原有完整缓存路径，否则恢复原生；本地/加密下载没有本轮新增范围适配。

## 播放修复

- 加载、Seek、恢复共用缓冲门槛；区分取消、替代、超时与源故障。加载中暂停保留必要准备，最终出声前核对最新位置和播放意图。
- 旧 Seek 的回复只表示取消，并回报实际位置；旧结果不能覆盖新操作或误走原生进度/暂停发布分支。异步 Seek 等待期间禁止用旧曲尾重新预约；提交新位置时取消旧预约，再按新 End 调度。
- 同采样率仍使用同钟预约；不同采样率重建输出，允许短间隔，不强制重采样来制造无缝。
- 普通 Load 保存唯一队列行。缓存读取故障需要原生重新授权选曲时，可以执行原客户端选择流程；实测暴露的缺行回退失败已修复。

不新增 CSS、EQ、混音、裁剪或降档。原有歌词、频谱时钟、菜单和系统媒体机制保留；Web 输出与原生/DAC bit-perfect 不作承诺。

## 日常验收

| 场景 | 本轮结果与口径 |
|---|---|
| 原生清缓存后的首曲 | 原生数据源，Load 就绪 851 ms；请求到 playing 状态约 1150 ms，非第一声测量 |
| 加载中暂停 | 实际 SDK 暂停发生于缓冲等待；最终 owned、暂停、无回退 |
| 连续 Seek | 旧请求取消，最新 180 秒生效；暂停意图保留 |
| 暂停/恢复与自动跨曲 | 最后一次录音在暂停准备曲尾后恢复，随后实际跨至 Open Hearts |
| 实际曲间声音 | NetEase 应用回录覆盖边界前后 2 秒，96,000 个 48 kHz 帧；无连续零样本或低于 −80 dB 的间隔，时间戳连续；此单曲对结果不能推广至所有网络与音源 |
| 原生接认 | 约 0.16 秒级，具体看记录；接认延迟不是断音长度 |
| 歌词、频谱、上一首/下一首 | 原页面样式保留，实际页面更新与控件可操作；未改变 0.2.3 频谱数据包规格 |
| 正常退出和重启 | 两首缓存的 6 个文件退出后哈希不变，原生元数据识别；插件读命中 15 次、辅助批次 0，复用已提交区间 |
| 清缓存 | 实际原生 SDK 清理与完成通知通过，队列归零、Web 所有权保留；93 个原文件已按 SHA256 恢复 |
| 读取失败与关闭 | 安装代码的临时读取拒绝复测确认原生恢复；关闭后同曲/位置/暂停，原生 gain 释放、工作缓冲归零 |

自然跨曲从曲尾 7 秒处恢复后跨越，未让 JS End 回调决定出声；没有连续播放整张专辑的长时验收。首轮异步 Seek 曾误沿用旧预约，已修复；早期几段录音未覆盖真正边界，未用它们宣称声音通过。真正覆盖边界的回录和协议记录单列在证据中，原始音乐不上传。

系统采样覆盖 240 次播放状态，但本轮没有完成控制中心拖动全矩阵；已知原生与插件均出现的进度回跳仍保留。不同规格、特殊音效、设备变化、真实磁盘权限失败、弱网和极端并发未全面验收。通过的是上述日常场景，不是所有副作用均消失。

发布包 `releases/gapless-player-mac-0.3.1.plugin`。同 slug 只保留一个启用包；安装前旧 0.2.4 包已移到插件目录外备份。包 SHA256：`5e6c1e2209760462b75deaaad97555286f41c41c3d87cd73e04189694165add0`，安装包、runtime 与交付副本一致。关闭菜单中的“无缝播放”会停止 Web 输出与辅助取数，恢复原生并持久保存开关。旧包回退应先正常退出，再替换包并重启宿主。
