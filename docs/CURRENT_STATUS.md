### 前版 0.3.11 索引解码证据

本轮捕获曲目 22676181 在 220.087 秒回退原生的 `stream-integrity` 记录，并独立复现同一原生缓存约 226 秒分块的解码短结果：应为 88064 帧，旧路径只返回 87040 帧。播放器会提前准备后续区间，所以分块故障可在曲尾前发生。

Mac 0.3.11 / Windows 源码 0.4.15 以有界下一帧前瞻和流式解码识别真实边界，仍严格校验采样数与格式，检查内置解码器实际错误数组，保留具体区间失败原因。该缓存 123 个索引区间全部通过；原问题段与相邻区间连续解码的对应 PCM 最大差值为 0。该轮安装 Mac 0.3.11，对仍在播放的 0.3.10 页面接入解码热修复，未重载、停止音乐或操作系统控件。该轮没有新增声音回录；完整 Mac 页面重载已在 0.3.12 完成，Windows 本轮未操作。见 [修正范围](INDEXED_DECODER_0.3.11.md)及[数值记录](verification/mac-indexed-decoder-0.3.11.json)。

热修复后另观察到 29567155 → 29750586 自然预约跨曲，客户端接认约 197 ms，没有回退。参数间隔 0 帧不等于声音回录结果，原问题曲目未在完整新版页面中从头重播。

0.3.10 的无关队列更新预约保留修复继续有效。该轮自然完成 Open Hearts → Moth To A Flame，接认约 319 ms；无关队列更新／接认中更新分支未做实机故障注入。见 [历史修正](QUEUE_BOUNDARY_0.3.10.md)。真实源、缓存、权限或输出故障仍保留原生回退。

## 当前能力与限制

网易云负责授权、档位、队列和持久缓存；两端受支持 FLAC 复用同源内存、原生有效磁盘区间／明文本地文件，缺口由串行原生 Load → Seek → Stop 准备、提交，插件只读并解码，Web Audio 连续输出。用户 Seek 和当前曲优先；空闲时有界后台补齐，不阻塞播放、不保证退出前整首缓存。编码区块共享 64 MiB，索引路径每曲 PCM 32 MiB。

同采样率下一首就绪时提前预约，异率重建输出可能有短间隔；未知格式／权限／客户端保留原生回退。无缝优先，原生专属音效在 Web 期间不执行，原偏好供关闭后沿用。Windows 重新开启等下一次有效 Load，Mac 可准备当前曲。

主要职责均有实现和分阶段证据，不等于所有设备、极端网络或插件兼容完整验收。Mac 控制中心进度回跳仍存在原生对照问题；Windows 既有 SMTC 实测未提供时间线／Seek。后台提交和清理屏障不是原生原子 flush 保证。
