## 本轮变更和验证

Mac 右上角复用原按钮，默认无缝开关、状态和「管理已安装插件」；管理页保留内置歌词窗口及已安装插件、宿主兼容提示、返回和原卸载确认入口。通用市场保持隐藏，不把 Windows 插件的可安装性当作 Mac 兼容证据。菜单样式限定自己的弹层，窗口、歌词布局和音频链路不改。

关闭验证发现页面恢复后尚无原生 Load 时，同曲重新选择会走 Resume 捷径并超时丢位置。0.3.8 改为用已验证的原生 SDK 重建同曲实例，自动 Play 不下发声音；SDK 完成后恢复目标进度和最新播放意图，隔离迟到 Load。避免强制重新选曲带来的迟到 Playing／旧 Seek 更新。开关保存加串行保护，切换管理视图期间仍禁用重复提交。

实机完成默认菜单、管理／返回、保存锁定、Esc 关闭、安装／运行版本、原生恢复、重新开启后的短时播放／暂停／Seek。最终恢复 Open Hearts、10.153351 秒、暂停、无缝开启、音量 0.48，原淡入淡出设置和关闭的歌词窗口保留。关闭后原生进度 10.15 秒、应用和实际均暂停、Web 音乐节点为 0；本次重建含准备耗时约 2.55 秒，不是声音接缝测量。[详细范围](PLUGIN_MENU_ALIGNMENT_0.3.8_0.4.12.md)，[机器记录](verification/mac-menu-0.3.8.json)。

Windows 0.4.12 上游记录确认 compact 菜单、BetterNCM 默认无缝配置、缓存起播、曲尾 Seek、自然接续及开关，预约间隔 0 帧，没有新声卡回录。上游移除未使用 LibEAPIRequest 后市场在线列表可加载，NativeWindowControls 保留；本轮未重装或再次实测 Windows。

## 当前能力与限制

网易云负责授权、档位、队列和持久缓存；两端受支持 FLAC 复用同源内存、原生有效磁盘区间／明文本地文件，缺口由串行原生 Load → Seek → Stop 准备、提交，插件只读并解码，Web Audio 连续输出。用户 Seek 和当前曲优先；空闲时有界后台补齐，不阻塞播放、不保证退出前整首缓存。编码区块共享 64 MiB，索引路径每曲 PCM 32 MiB。

同采样率下一首就绪时提前预约，异率重建输出可能有短间隔；未知格式／权限／客户端保留原生回退。无缝优先，原生专属音效在 Web 期间不执行，原偏好供关闭后沿用。Windows 重新开启等下一次有效 Load，Mac 可准备当前曲。

主要职责均有实现和分阶段证据，不等于所有设备、极端网络或插件兼容完整验收。Mac 控制中心进度回跳仍存在原生对照问题；Windows 既有 SMTC 实测未提供时间线／Seek。后台提交和清理屏障不是原生原子 flush 保证。
