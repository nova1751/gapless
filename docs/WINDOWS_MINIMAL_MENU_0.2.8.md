# Windows 0.2.8：收窄菜单与恢复状态

按用户最新要求，右上角菜单只保留无缝播放一行及一个开关；移除其他宿主插件列表、管理按钮和版本标签。没有新增插件依赖；原有 BetterNCM 宿主与窗口按钮修复组件仍保留。

普通 recover 原生恢复事务现在计入 handingBack 状态，避免菜单在恢复尚未完成时提前允许重复切换。

验证：
- 0.2.7 播放中关闭：恢复同曲约 21.769 秒位置并继续原生播放，约 1.2 秒后确认 owns=false、nativeMuted=false、activeNodes=0、resources.held/reserved/pending 全为 0。
- 0.2.8 增量语法和 ZIP 打包通过，运行包版本确认。
- 运行页面菜单结构确认只有 1 行、1 个 switch；开启且未播放时没有 AudioContext。
- 强制结束进程的关闭配置持久化复查未通过：关闭后存储中为 false，强制重启后读到 true。原因尚未确认，不能将此前一次保留成功描述为所有重启情形可靠。本轮最终按用户原先偏好保留开启。
- 没有新增设备音频回录、多 DPI 或浅色主题验收。
