# Mac 快捷菜单 1.2.1

本文保留菜单 1.2.1 的实现与验收；播放器当前已更新到 [0.3.10](QUEUE_BOUNDARY_0.3.10.md)，菜单版本不变。

基于 main d82634d，菜单源码、安装及运行版本为 1.2.1；Mac 无缝播放器仍为 0.3.9，Windows 0.4.14 未修改。[版本与哈希](versions.json)。

## 使用与边界

右上角插件按钮打开宿主样式快捷菜单，上方「无缝播放」开关，下方「管理插件」。点击管理插件进入原 BetterNCM 管理页：左侧选择已安装插件，右侧查看详情及插件自己的配置。无缝配置复选框和快捷开关共用播放器原有启停事务、保存锁和原生恢复流程，显示同一实际状态。

菜单复用宿主弹层颜色、字号、间距和滑动开关。保存／恢复期间禁用开关，读列表失败时禁用快捷开关并显示重试提示，管理入口仍可使用。点击外部、Esc、调整窗口尺寸时收起弹层；关闭菜单后取消轮询，页面卸载清理监听中的工作。插件没有加载时通过宿主保存后刷新加载；管理页操作恢复该页，快捷菜单操作保留网易云页面。

PluginMarket 独立启停，关闭市场仍可管理插件和控制无缝。管理页保留 Mac 兼容提示：很多市场插件面向 Windows，尤其 DLL／原生接口依赖，不能直接在 Mac 使用；下载和安装由用户决定。本轮未调整市场偏好或安装其他插件。

## 验证与回退

Mac 原生界面核对菜单布局、快捷关闭与管理复选框同步、管理开启与快捷开关同步、原生恢复、关闭后重载与未加载插件重新启用、管理页返回、Esc 和外部点击收起。最终保留无缝开启、市场开启、歌词窗口关闭、Open Hearts 暂停。深色界面已观察；浅色配色复用宿主变量，未另行切换验收。

机器记录见 [1.2.1](verification/mac-quick-menu-1.2.1.json)。播放包、安装包及运行文件与此前 0.3.9 一致，本轮不改音源、解码、增益、采样率、排程、歌词或频谱，不新增音质或所有设备兼容结论。市场启停与原配置证据保留在 [1.2.0](MAC_PLUGIN_MANAGER_1.2.0.md)。

安装仅执行 `python3 mac/install-menu.py`，再通过宿主重载插件并刷新。`python3 mac/install-menu.py --remove` 可移除菜单扩展，下次重载恢复宿主原入口。播放器旧包 0.3.8 仍保留在活动插件目录外供回退。Windows 保留最新上游菜单与管理流程，本轮未操作 Windows 设备。
