# 0.1.10：优先复用网易云播放缓存

本版把网易云完整磁盘缓存接到原有独立资源管线。只影响桥接前的音频准备；普通播放和桥接后仍由原生后端出声，不增加音质选择、音效或界面样式。

## 读取顺序与身份检查

1. 优先使用账号范围、请求档位及音源身份匹配的已解码内存缓存。
2. 用网易云当前授权音源的歌曲 ID、实际音质和 MD5 调用原生 `Storage.getTrackFromCacheFast`。记录必须完整（`cached=100`）、为本版已验证的 `et=1`，并且歌曲、码率、MD5、实际档位、音源长度一致；试听不复用。
3. 只在网易云配置的缓存目录及已验证的默认目录查找精确文件名，不扫描全盘。以异步宿主接口查询元数据并读取本地文件，避免同步文件 API 阻塞页面。
4. 支持本机 3.1.12 的 UC 缓存格式：在内存中按 XOR A3 还原原始编码字节，并对完整字节流计算 MD5。大小及 MD5 均匹配后，才交给原有 OfflineAudioContext 解码；不写入或改造网易云缓存，不解密 `.info` 文件，也不导出音乐。
5. 缓存缺失、不完整、不同音质、不同内容、格式不明、读取失败或完整性校验失败时，使用当前授权音源。格式、采样率、解码或预算不兼容时保持原生，不重复下载同一份不兼容的文件，不另选低音质。

“播放过”不保证可复用：缓存可能被清理或只缓存了一部分，之前播放时选择的音质也可能不同。缓存记录不是离线授权；候选仍按网易云当前请求确认权限与实际音源。

## 对播放的影响

缓存读取不会启动音乐播放上下文，不改变位置、队列、用户音量或原生状态。文件还原和哈希以最多 64 KiB 的片段处理，累计约 6 ms 后让出页面任务；仍使用原有编码文件上限、串行解码和 512 MiB 管理预算。缓存读取阶段设 8 秒上限，整个资源任务保留原有 25 秒上限；取消、换歌和关闭开关会中止读取。后台定时器可能被系统节流，因此时间上限不能作为硬实时保证。

缓存可减少重复下载与网络等待，不能免除解码，也不能解决两个输出后端计时及 macOS NowPlaying 状态发布的所有限制。没有准备完整就保持原生，不在切换瞬间读取文件或计算 MD5。

## 当前验证状态

0.1.10 首次集成时因锁屏/文件打开挂起，读取未验收；其历史记录保留在 [0.1.10 记录](verification/mac-cache-priority-0.1.10.json)。后续文件服务恢复，0.1.11 已实际安装、重载并完成以下场景：

- Baptized In Fear 与 Open Hearts 的完整原生缓存分别读取 27081483 与 27865486 字节；还原后完整 MD5 与当前授权源一致，来源为 `native-cache`，源与解码均 44.1 kHz、双声道。
- 两首实际进入主播放器预加载。当前选择仍为 Hi-Res，网易云本次实际返回 lossless；沿用该原生结果，未改变用户选择。独立资源核对约 0.89/1.06 秒完成，不作为所有磁盘性能保证。
- A→B 预约参数间隔 0 帧，B 约 10.37 秒交还原生，之后音乐节点与上下文归零；原生输出恢复，用户音量仍为 0.48。
- 实机期间 `window.fetch` 的 Web 音频文件下载请求为零；只覆盖 Web 预加载，不统计网易云原生后端网络活动，授权元数据请求仍可存在。
- 主动 Seek 取消预热后原生采用目标位置且释放 Web 上下文；一次注入输出时戳错误后实际上下文为 `closed`，原生继续报告播放中。探针已撤销并恢复验证前的歌曲、47.1 秒位置、暂停意图和音量。

证据见 [0.1.11 实机记录](verification/mac-runtime-0.1.11.json)。没有保存音频文件或签名 URL，没有新增测试用例、执行应用构建或全量静态检查。Native 窗口样式已观察，但未完成设备回录、系统图标闪动修复或所有格式/设备/异常组合验证；预约、协议状态和缓存命中不能单独证明绝对无间隔听感。
