# Mac 缓存读取恢复（0.3.14）

2026-11-23，基于远程 main `d54f990`。Mac 3.1.12（3444）＋ BetterNCM-mac 0.1.7；菜单 1.2.1、Windows 0.4.21 保持原实现。

## 原因与证据

之前的直接故障是原生缓存读取链路返回 `Failed to fetch`，插件为保护播放而交回原生，无缝预约因此失效。早期线程采样另确认过宿主同步文件打开阻塞；0.3.13 已绕开同步索引读取。本轮没有重现持续的真实缓存读取失败，不能把文件替换、锁屏、系统授权或文件损坏认定为昨天的确切触发原因。

宿主挂载文件路由在文件流错误时直接销毁 HTTP 连接，没有上报文件系统错误码，浏览器只得到通用网络错误。插件原先只对读取后文件属性变化重查一次；索引读取失败、已验证路径消失及流断开会立即结束读取，缺少从原生重新确认有效文件／区间的机会。这是本轮修复的确定代码缺口。

同一授权歌曲 431811451 的原生索引和缓存当前可读。部署前读完 26,511,114 字节并校验 MD5，约 1,062 ms；部署 0.3.14、经宿主已有接口重载后再次复用原生缓存，完整读取与 MD5 共约 1,023 ms，有效索引为一个完整区间。Hi-Res 请求由网易云返回 lossless FLAC，插件没有改变请求档位、替换音源或重新编码。整首编码字节匹配不代表新完成了设备输出音质对照。

## 修复

- 索引和音频区间复用同一个有界挂载读取方法；流失败时清除该文件的挂载引用，返回明确的读取不可用原因。宿主 API 无法连接或 HTTP 响应失败分别记录，避免都混成通用 `Failed to fetch`。
- 索引暂时不可读时继续检查原生另一种文件名／缓存根目录，仍须核对授权记录、文件版本、有效区间。音频路径消失、尺寸变化或 Range 失效时重新取得索引。
- 一次区间请求最多重查一次，包含索引和音频失败在内，共用原有 8 秒期限；正常读取没有新增等待。持续失败仍原生回退，不放宽 Range、FLAC、采样数或 MD5 校验，不增加 Web 下载与永久缓存。
- 重查前后复核取消与源有效性。用户取消不记作源故障，自己的读取期限到期明确记录为 `native-only-cache-read-timeout`。运行状态增加 `nativeCacheSource.refreshes`，记录实际重查次数。

## 验证与交付

实际加载的 0.3.14 生产方法结合真实原生缓存做定向诊断：正常头部读取约 51 ms、重查次数 0；一次索引故障、一次音频故障、失效路径分别重查一次并读到有效 FLAC。持续故障重查一次后返回明确失败；主动取消不重查、不计故障；超时约 8,005 ms 退出。不创建测试用例、不修改用户缓存或宿主安全策略。这些故障检查使用独立诊断实例，没有替换实际播放器的数据读取函数。

部署前的 0.3.13 实际续播自然完成 The Hills → One Of The Girls：同为 44.1 kHz，预约间隔 0 帧，原生界面接认约 188.3 ms，未回退；窗口显示新曲并可暂停。这是播放协议及界面证据，没有音频回录，不能作为部署后 0.3.14 的声音接缝验收。随后窗口工具返回 `cgWindowNotFound`，部署后的声音、歌词、频谱和系统控制未再次实测。

0.3.14 包、安装包、运行文件及实际页面版本一致；旧 0.3.13 包留在插件目录之外用于回退。已恢复 The Hills、约 218.16 秒、暂停、原 Hi-Res 设置；重载后的客户端保存位置为 218 秒，没有 Web 音乐节点或加载门控残留。详细字段见 [机器记录](verification/mac-cache-read-recovery-0.3.14.json)。

仅执行修改 JS 语法检查、生产方法定向诊断、真实缓存读取、ZIP／安装一致性和播放状态确认；未新增测试用例、全量静态检查或应用构建，没有操作 Windows。

仍有明确限制：系统持续拒绝／挂起文件访问不能由一次重查解决，宿主丢失和永久读取错误仍回退原生；昨天系统文件打开阻塞的具体触发未确定。本轮修复瞬时读取失败的恢复能力，不能宣称全部系统级缓存故障或声音卡顿已消除。
