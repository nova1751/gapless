# 跨平台无缝播放实现原则

源码、安装与实测版本统一见 [当前状态](CURRENT_STATUS.md)及[版本记录](versions.json)。历史矩阵 [Windows 0.4.6／Mac 0.3.3](PLATFORM_ALIGNMENT_0.4.6_0.3.3.md)保留当轮证据，不表示当前版本或完整验收。[最新菜单／市场范围](MAC_PLUGIN_QUICK_MENU_1.2.1.md)。

## 职责与不变量

网易云负责授权、音源档位、队列、音量偏好和持久缓存；插件读取可信有效区间、独立解码并以一个 Web Audio 时钟连续输出。无缝启停置于宿主管理范围，不改歌词或主窗口布局，不做 EQ、交叉淡化、静音裁剪或降档。

无缝开启后优先连续输出，冲突的原生专属音效不在 Web 链路执行，保存值供关闭后的原生使用。未知客户端、协议、权限或不可播放格式回原生。共用核心不代表平台桥、缓存格式、系统控制、耗时或最终设备输出完全相同。

## 生命周期

1. 启动时装桥、读持久化开关；初始化命令队列有数量和时间上限，失败放回原生。AudioContext 按真实音源采样率创建，真实输入授权不足时等待，不先发原生声音再追赶。
2. 原生解析器取得有效当前资料后准备资源，核对授权、源身份、档位及取消代次；先复用匹配内存，再读有效原生区间／本地文件，缺口由原生辅助任务准备。暂停状态可准备，不能因此自动播放。
3. 启动声音／Seek／恢复／接认前重新核对当前实例、代次、源身份和最新意图，旧结果不能覆盖新操作。下一首准备失败不影响当前声音。
4. 下一首首段就绪、队列可信时按当前音频时钟提前预约 start(when)，不等 JS End 回调才开声。同采样率可连续；异率重建输出可能有短间隔。
5. 手动选曲取消旧节点和预约，复用可信暖缓冲与同率上下文；不添加人为切歌等待，但原生 Stop → Load、授权与准备耗时仍存在。
6. 关闭时取消任务与预约、停止 Web 输出和显示 PCM、恢复同曲位置／音量／最新播放意图，释放工作缓存。恢复事务和开关保存串行化。Windows 重新开启等下一次有效 Load；Mac 可准备当前曲，两端无需强行使用相同平台动作。
7. 换曲、队列、账号／档位变化、清缓存、退出取消旧任务；辅助通知不能覆盖主曲目、歌词、进度或系统播放状态。

## 缓存与计算

- 文件长度、缓存百分比和 Buffer 通知不能独立证明有效区间。读取稳定 IDX 及源身份；完整 MD5 在读取结束时验证，流式起播不能称为出声前已验完整文件。
- 插件不写 UC／IDX，原生 Load／Seek／Stop 负责取数与提交，辅助实例不 Play。不要用第二套永久音乐库、仿写索引或跳到曲尾来替代提交证据。
- 当前播放、用户 Seek 优先；PCM 安全余量充足时才后台补缺口。最多保留最近两首、十分钟的待补齐元数据，有期限／无进展退避，不为补齐阻塞播放，不保证退出前整首缓存。
- 编码区块共享 64 MiB，索引路径每曲 PCM 32 MiB，其他路径受 512 MiB 管理预算约束；可选最近一首暖缓冲也受总预算约束。
- 缓存清理取消辅助任务，观察停止后的索引／元数据稳定，有时间上限，失败仍转发原请求；不是原生原子 flush 的证明。
- CryptoJS core/MD5 与 FLAC 解码库固定内置。宿主禁止 Worker 时采用有界分块路径，不修改 CSP，不加载 CDN 或远程代码。

## UI 与兼容

Mac 右上角快捷菜单上方是「无缝播放」开关，下方「管理插件」进入 BetterNCM 管理页，左侧选择插件，右侧显示详情、启停及原有配置；快捷开关与配置复选框复用宿主认证 API、`onConfig` ／`tools.makeCheckbox` 与原有无缝启停事务，同步保存和运行状态。市场关闭后管理入口仍保留。兼容说明可见，下载和安装由用户决定。Windows 复用 BetterNCM 管理页及其兼容规则。大部分 Windows 原生插件不能直接迁移 Mac；一个兼容提示不构成运行验收。菜单扩展与播放器独立安装／回退，不增加音频控制链路。

## 验证口径

分别记录真实点击到声音、授权／读取／解码、输出上下文及门、宿主 Stop → Load、曲间预约帧数、客户端接认延迟和设备回录接缝。预计输出、零帧预约和接认延迟不能替代声音回录。

优先普通使用回归和增量检查，不新增测试用例或默认运行全量静态检查、应用构建。记录缓存有效区间、重启复用和原生回退证据；未通过项明确保留限制。Mac 控制中心进度回跳、Windows 系统时间线、弱网／设备切换和最终 bit-perfect 均不能靠源码相似度宣布解决。
