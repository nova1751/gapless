2026-11-17 拉取 main 至 `234ab6d`。Windows 当前无缝插件为 **0.4.13**，本次上游仅修复标题栏悬浮高亮；Mac 无缝插件 **0.3.8** 保持不变，独立菜单更新至 **1.1.0**。安装、运行、哈希与历史证据分开记录在 [versions.json](versions.json)。

## 市场使用

本机已安装菜单并启用宿主内置 **PluginMarket 0.8.0**。右上角插件图标 →「插件市场」；同一入口的「返回网易云」关闭市场。原插件列表、详情、下载控制由宿主提供，用户决定是否下载和安装。

其他 Mac 安装菜单：`python3 mac/install-menu.py --market`，随后宿主重载并刷新，或正常退出后重新打开。首次进入可能显示宿主介绍页。只保存原有 `mac.pluginManager=true`，不改执行权限、文件权限范围、CSP 或其他配置；普通安装不改变市场启用设置。`--remove` 只移除独立菜单，已保存的市场设置保留。

菜单通过原管理按钮触发宿主布局与导航；标题栏只保留一个入口。市场中增加 macOS 兼容说明及实际宿主 **0.1.7**。原标题 **1.3.4** 是宿主模拟的兼容接口版本，不是 Mac 发行版本。市场包含 Windows 原生插件，可浏览、可下载不表示已在 Mac 验证兼容。

本轮本机检查市场列表、一个插件的详情与下载按钮、兼容／版本说明、返回、重新打开、标题栏及侧边栏／底部播放区。没有点击下载／安装其他插件。打开、重载、返回后曲目与 **10.153351 秒、暂停、无缝开启** 的意图保留。菜单安装哈希、播放器包哈希及运行版本已核对，见 [机器记录](verification/mac-market-menu-1.1.0.json)。
