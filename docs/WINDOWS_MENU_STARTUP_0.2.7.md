# Windows 0.2.7：插件菜单与首曲入口

基于 origin/main f6a4b72，以及本地 Windows 0.2.6 的缓存与直接 Web 播放代码。安装前发现实际运行的是另一份带菜单的 0.2.4；已备份，避免继续覆盖 0.2.6 的音频修复。

## 改动

- 右上角插件图标与原设置等按钮并排。320px、12px 圆角菜单，36×22px 无缝开关；读取宿主实际插件名称和版本。其他插件进入原宿主管理，不另建加载器。
- 菜单和设置页使用同一个无缝控制接口。原生恢复中暂禁重复点击；样式只作用于插件节点。
- 歌词顶栏自动隐藏/重建时，已展开菜单保留位置，不再连带关闭导致开关无法点击。
- 启动脚本同步截获 channel 创建，主控制器未就绪时，已明确开启的配置最多暂存 2.5 秒/32 条播放命令，并按原顺序交给控制器。关闭或无法读取配置时放行原生；超时原生实例禁止随后自动追赶接管。
- AudioContext 仍在源规格确定后创建，未播放时不提前固定输出采样率；保留完整缓存校验、网易云授权源与档位。

## 本次检查

- Node 增量语法与 ZIP 打包通过。一次性内存协议检查通过：同步 channel hook、顺序排队/重放、超时原生放行、关闭模式透传；没有新增测试文件。
- 实机运行 0.2.7。进程启动后控制器已就绪，AudioContext 尚未创建。
- 真实点击首次播放 Baptized In Fear：本地原缓存 MD5 校验命中，lossless，源/解码/输出均 44100 Hz；原生 Load/Play/Pause/Seek 计数均为 0。Open Hearts 预取也命中原缓存，预约边界差 0 帧。这是协议和调度证据，本轮没有追加设备音频回录。
- 主界面关闭图标仍为 x=1309,y=26,20×20，颜色 rgba(255,255,255,.6)。移除/恢复插件图标时关闭按钮几何和颜色相同。
- 主界面和歌词页菜单真实点击开/关通过，歌词顶栏隐藏后开关仍可点击。点击外部关闭通过，重启后开启状态保留。
- 本次实查当前深色主题/当前缩放，未穷举浅色主题、多 DPI、系统媒体控制或所有冷启动竞态。
- 最终包 SHA256：30DD11797F859C969E3CA28A5BCF9BE5D222761B35CB1C5F12BEB6D5FB4354BA。安装包与工作区产物一致。诊断/探针/临时交还模式均关闭。

首次校验/解码仍有准备时间；没有承诺零加载时间或与原生比特相同。菜单复用现有宿主管理能力，不代表 Windows 已移植 Mac 宿主全部功能。
