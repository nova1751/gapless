# 0.1.11 源码复查与 Windows 方案交付

日期：2026-11-14。本轮检查范围为缓存优先、临时 Web 桥接、双向交还、控制代次、失败收尾及 Windows 文档一致性。不是全部声音/系统行为验收通过的声明。

## 发现并修复

接管失败或取消后，原实现停止静默节点但可能保留预热 AudioContext，导致之后的原生播放期间仍持有输出上下文。`mac/player.js` 现于未拥有 Web 音乐播放时关闭该上下文，关闭完成前保留接管锁，防止后续接管复用正在关闭的设备。收尾失败写入诊断，并释放接管锁。

同时将等待真实输入的判断直接绑定到 `awaitingGesture`，由已有 pointer/keydown 入口解除。这样关闭 suspended 上下文后不会在无手势时反复创建新上下文。没有新增音乐效果、位置校正、音量策略或 CSS。

Windows 方案 v8 已整体重写：临时约 10 秒曲尾/曲头窗口、双向校准、同钟 A→B 预约、缓存优先、原生接认与交还、Seek/媒体输入路由、系统权威状态、UI、适配器契约、实施阶段和手动验收。移除旧的整首/整队列 Web 接管步骤及过时 Mac 版本陈述，不再依靠开头一句警告修饰相互矛盾的流程。

## 复核结果

| 项目 | 结果与限制 |
|---|---|
| 原生优先 | 普通阶段保持原生；只有可信下一首与两首资源兼容且准备完整才进入桥接 |
| 暂时接管 | A 尾部桥接、B 头部交还；B 不再预约 C；主动 Seek/暂停可提前交还 |
| 源和音质 | 缓存按当前授权源身份、实际档位、大小与 MD5 校验；不新增低音质回退或 DSP |
| 异步与预算 | 缓存目录/文件异步查询，64 KiB 分段校验；任务有取消、限额和有限等待，不在切换时读盘 |
| 控制和恢复 | 复核实例/Load/控制/队列代次；原生静默准备保存用户音量，成功、取消和故障均恢复 |
| 预热资源 | 本版补失败/取消后的关闭及真实输入保护；已实机确认主动 Seek 取消后节点/上下文退出，以及一次输出时戳故障注入后上下文关闭 |
| 样式 | 本版只改音频收尾与文档，没有 CSS/DOM 样式变更；没有把系统图标闪动写成已修复 |
| Windows 一致性 | 当前方案不再规定整首 Web 播放；所有平台接口和缓存格式均要求目标 Windows 实查 |

源/PCM/上下文规格检查不等于与原生设备输出比特一致，25 ms 估算误差也不是采样级证明。Mac 原生计时是粗粒度更新，运行中 Seek 不暴露精确相位；未获原生设备时戳前仍保留估算与回退边界。

## 已执行的验证

此前仅对四个变更 JS 文件做局部语法检查、ZIP 组合/校验和文档链接检查；没有新增自动测试、全量 ESLint/TypeScript 或应用构建。最初实机读取被锁屏/文件打开挂起阻挡，旧记录保留在 [0.1.10 缓存记录](verification/mac-cache-priority-0.1.10.json)。同日继续后文件服务恢复，现已补齐以下场景：

| 实机场景 | 本次结果 |
|---|---|
| 安装和重载 | 同 slug 只留一个包，发布/安装/解压内容一致；读取实际运行版本为 0.1.11 |
| 完整缓存及解码 | 两首完整本地缓存通过 MD5，主播放器实际来源 `native-cache`，源/解码 44.1 kHz 双声道；Web 音频下载请求零 |
| A→B→原生 B | Baptized In Fear → Open Hearts 参数预约 0 帧；B 10.3696 秒交还，Web 节点和上下文退出，音量 0.48、输出门控已释放 |
| 取消预热 | `warming`、真实上下文 running/一个节点时 Seek 到 45 秒；之后原生继续播放、位置约 45.62 秒、节点为零、上下文退出 |
| 预热失败 | 临时让真实 AudioContext 的输出时戳读取抛错一次；实际上下文随后为 closed，原生仍报告播放中，Seek 到 60 秒成功 |
| 原生恢复 | 验证前的歌曲、47.1 秒位置、暂停状态、音量均恢复，临时 fetch 计数和故障注入已撤销 |
| Native 窗口 | 原生布局/按钮样式保留，恢复后显示正常的暂停意图；未据此宣称系统控制中心闪动消失 |

完整记录见 [mac-runtime-0.1.11.json](verification/mac-runtime-0.1.11.json)，包核对见 [PACKAGE_0.1.11_SHA256.json](verification/PACKAGE_0.1.11_SHA256.json)。音频下载计数只统计 Web 准备期间的 `window.fetch` 音频文件请求，不统计原生后端网络活动。预热故障是一次手动注入，用来验证资源退出，不代表真实硬件错误已经穷举。
